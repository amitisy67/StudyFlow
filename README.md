# StudyFlow 📚⏱️

## About the Project

StudyFlow is a Python-based productivity application designed to help students organize their study sessions and improve their learning habits. The project combines subject tracking with a Pomodoro timer to help users manage their study time, monitor progress, and stay focused on their goals.

## What Does It Do?

StudyFlow allows users to:
- Create and manage study subjects
- Record completed study sessions
- Track total study time for each subject
- Use a Pomodoro timer for focused study sessions
- Store and manage study data for future use

## Technologies Used

This project is built with:
- Python 🐍
- Object-Oriented Programming (OOP)
- JSON for data storage
- Git & GitHub for version control

## Features

- Simple command-line interface
- Organized project structure
- Persistent data storage
- Time management using the Pomodoro technique
- Easy-to-expand design for future improvements
